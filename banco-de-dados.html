Bíblia Dourada

Banco de dados

Informações organizadas para leitura na própria página.

O aplicativo foi projetado para trabalhar com um banco SQLite local. O banco com conteúdo de estudo de terceiros não é redistribuído pelo projeto.

Funcionamento

  • O app pode criar um banco vazio com o schema necessário.
  • A importação é feita localmente.
  • Um banco .db precisa conter a tabela verse com registros para ser aceito.

Anotações JSON

{
  "format": "biblia-dourada/anotacoes",
  "version": 1,
  "language": "pt_BR",
  "annotations": [
    {
      "book": "Lev",
      "chapter": 1,
      "verse": 2,
      "text": "Texto da anotação"
    }
  ]
}

Importação

Abra Dados do aplicativo → Importar dados. O banco completo substitui o conteúdo; as anotações JSON são mescladas ao banco existente.

Privacidade

Os arquivos escolhidos são lidos localmente no aparelho. O projeto não redistribui o banco de terceiros.
