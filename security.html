Análise do aplicativo

O pipeline de publicação executa o MobSF (Mobile Security Framework) sobre o APK antes de publicar os arquivos de verificação no site.

O projeto utiliza a GitHub Action mantida por Fundação CERTI, disponível no GitHub Marketplace. A Action executa o MobSF em contêiner e gera relatório JSON e PDF.

A análise automatizada é uma camada de verificação e não equivale a uma certificação de segurança ou a uma garantia de ausência de vulnerabilidades.

Sobre a origem da análise

A Action utilizada é publicada pela Fundação CERTI no GitHub e aparece no GitHub Marketplace como “GitHub Action for MobSF”.

A Action é de terceiros e não é certificada pelo GitHub. A análise deve ser interpretada como evidência técnica automatizada, junto ao checksum e à assinatura do APK.
